Windows 10/11 (64비트)용 Sky CRM입니다. **SkyCRM-1.0.0-Windows-x64.exe**를 다운로드하고 실행하세요.
Python·브라우저·별도 설치 없이 사용할 수 있습니다. 통화 기록, 거래처 DB, 메모/할 일, 폴더와 페이지, 글자 서식, 첨부파일, 이미지 이동·크기 조절을 포함합니다.

데이터는 `%APPDATA%\SkyCRM`에 자동 저장합니다. EXE 파일 위치를 옮겨도 같은 Windows 사용자 계정에서는 데이터를 유지합니다. 웹 체험판이나 기존 Python 앱 데이터는 자동 이전하지 않습니다.

코드 서명 인증서가 없는 실행 파일이라 Windows에서 게시자를 확인할 수 없다는 안내가 표시될 수 있습니다.
