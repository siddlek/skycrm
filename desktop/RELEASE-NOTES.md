Windows 10/11 64비트용 Sky CRM 1.1.2입니다. **SkyCRM-1.1.2-Windows-x64.exe**를 내려받으세요. 기존 EXE를 완전히 종료한 뒤 실행합니다.

- 상단의 중복 파일/FTP 버튼 줄을 제거했습니다. 모든 기능은 원래처럼 **파일 메뉴**에서 사용할 수 있습니다. Ctrl+O, Ctrl+S, Ctrl+Shift+S도 지원합니다.
- 창 전체 대신 통화 기록·거래처 목록 안에서만 스크롤합니다. 신규 통화 입력과 검색 조건은 고정하고 표 제목도 유지합니다. 할 일·메모 목록과 편집 영역도 각각 내부에서 스크롤합니다.
- 앱 내부 데이터는 변경 즉시 저장하고, 입력이 멈춘 뒤 약 2초 후 선택한 JSON 파일에 자동 저장합니다. 이전 저장본 3개를 계속 보관합니다.
- FTP는 환경설정의 동기화 간격(기본 5분, 기존 10분 설정은 그대로 유지), 수동 저장, 프로그램 종료 시 동기화합니다. 종료 시 마지막 변경을 JSON에 저장하고 FTP 동기화까지 시도한 뒤 종료합니다. 실패하면 재시도·PC 저장본으로 종료·취소를 선택할 수 있습니다.
- 기존 데이터 파일 열기·다른 이름으로 저장·백업 3개 복구·FTP 불러오기/동기화, 메모 서식·이미지·첨부파일을 유지했습니다.

FTP 기능은 환경설정에서 FTP 또는 하드디스크+FTP 방식을 선택했을 때 적용합니다. PC와 FTP의 실제 저장·복구·주기적 동기화·종료 직전 저장을 Windows 앱과 루프백 테스트 서버로 검증합니다.
