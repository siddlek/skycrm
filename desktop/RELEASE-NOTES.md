Windows 10/11 (64비트)용 Sky CRM 1.1.0입니다. **SkyCRM-1.1.0-Windows-x64.exe**를 다운로드하고 실행하세요.

- 기존 `call_data.json`과 다른 이름의 JSON 데이터, `.bak1`·`.bak2`·`.bak3` 백업 파일을 열 수 있습니다.
- `파일 열기`, `저장`, `다른 이름으로 저장`, `백업 복구`와 자동 백업 3개를 복원했습니다.
- 하드디스크 / FTP / 하드디스크+FTP 저장, FTP 파일 목록과 불러오기, 연결 테스트와 동기화, 기존 `call_settings_lite.json` 가져오기를 지원합니다.
- 새 메모의 페이지·서식·이미지·첨부파일 원본까지 JSON/FTP 백업에 포함합니다.
- 거래처 DB 목록 높이와 통화 기록의 거래처명·연락처 입력칸 너비를 늘렸습니다.

PC에 있는 기존 데이터는 **파일 열기**로 선택하세요. FTP 데이터는 **환경설정**에서 서버 정보를 입력하거나 기존 설정 파일을 가져온 뒤 **FTP에서 불러오기**로 선택하세요. 같은 이름의 서버 파일을 먼저 불러오기 전에는 덮어쓰지 않습니다.

저장할 때 현재 JSON과 같은 폴더에 이전 저장본을 최대 3개 보관합니다. 백업을 선택하면 미리보기로 열며, Ctrl+S로 저장해야 현재 파일에 반영됩니다. 다른 PC에서 같은 FTP 파일이 바뀌면 동기화를 중단하고 알려드립니다.

1.0.0 EXE에 입력한 데이터는 같은 Windows 계정의 `%APPDATA%\SkyCRM`에서 유지합니다. 웹 체험판 데이터는 자동으로 옮겨지지 않습니다.

Python·브라우저 설치 없이 사용할 수 있습니다. 코드 서명 인증서가 없는 실행 파일이라 Windows에서 게시자 확인 안내가 표시될 수 있습니다.
