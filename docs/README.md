# Sky CRM 웹 체험판

설치 없이 사용하는 정적 웹 체험판입니다. 통화 기록, 거래처 DB, 메모 탭에서
추가·수정·삭제할 수 있고, 메모를 할 일로 만들거나 완료 처리할 수 있습니다.
통화 기록 표의 `할 일` 체크박스는 통화 내용을 메모 탭의 할 일로 연결합니다.

통화 기록은 원본 앱의 입력·기간 검색·표 구성을 따르며, 거래처 DB는 전화1/2/3과
메모 열을 제공합니다. 표의 셀을 더블클릭하면 수정하고 열 제목으로 정렬할 수 있습니다.

할 일과 일반 메모는 각 목록 제목 옆의 `+` 또는 우클릭 메뉴에서 추가합니다.
목록의 이름을 더블클릭하면 수정하고, 항목 우클릭 메뉴에서 삭제합니다.
편집 제목 옆에서 종류를 바꿀 수 있습니다. 일반 메모에서는 전화번호를 표시하지 않습니다.
예시 데이터 생성, 텍스트 다운로드, 줄바꿈 버튼은 없습니다.

할 일은 행 전체를 끌어 다른 행 **가운데**에 놓으면 하위가 됩니다. 위·아래 **가장자리**에
놓으면 같은 단계로 이동합니다. 빈 공간에 놓으면 최상위로 이동합니다. 순환 관계는 차단합니다.
목록과 편집 사이 구분선을 끌거나 방향키로 너비를 조절하며 비율은 브라우저에 저장합니다.

일반 메모는 이름순·최신 수정순·최신 생성순·직접 정렬을 선택할 수 있습니다.
직접 정렬은 행을 다른 행 위·아래로 끌어 변경합니다. 메모를 폴더 행에 놓으면 폴더 안으로
이동하고, 목록 하단 빈 공간에 놓으면 폴더 밖으로 나옵니다. 폴더는 중첩할 수 있습니다.
폴더만 삭제하면 안의 메모와 하위 폴더는 상위로 옮겨 보존합니다.

각 메모에는 여러 페이지가 있습니다. 페이지 옆 `+`로 추가하고 `×`로 삭제합니다.
페이지 이름은 더블클릭하거나 우클릭 메뉴로 수정합니다. 기본 이름은 `새 탭`, `새 탭1`, …입니다.
기존 단일 메모는 내용과 이름을 유지하며 첫 페이지로 변환합니다.
메모/페이지 삭제는 확인 후 해당 내용을 제거합니다. 내용은 입력 즉시 자동 저장합니다.
실행 취소/다시 실행과 글자 수·줄 수를 지원합니다.
`Ctrl+F` (Mac `Cmd+F`)로 찾기·일괄 변경 창을 열고 `Esc`로 닫습니다.
검색과 변경은 대소문자를 구분하지 않습니다. 찾기 UI는 편집창에 상시 표시하지 않습니다.

기록은 현재 브라우저의 localStorage에 저장합니다. Python 앱의 데이터와 연동하거나
다른 기기와 동기화하지 않습니다. 공개 체험에서는 예시 정보를 사용하세요.
백엔드, 계정, API 키, 외부 라이브러리 CDN은 필요하지 않습니다.

## GitHub Pages 배포

1. `docs/`와 `.github/workflows/web-preview.yml` 변경을 GitHub 저장소 main에 반영합니다.
2. 저장소 Settings → Pages → Build and deployment → Source를 **GitHub Actions**로 설정합니다.
3. Actions에서 **Deploy web preview to GitHub Pages**를 실행합니다.
4. 성공한 실행의 `github-pages` 배포 URL을 열면 됩니다. 실제 URL은 실행 결과로 확인하세요.

이 설정은 웹 체험판만 배포하며 기존 Windows EXE 빌드 워크플로와 독립적입니다.
GitHub 계정/저장소 요금제에 따라 Pages 사용 가능 여부와 공개 범위가 달라질 수 있습니다.

로컬 개발 시 `python -m http.server 8000 --directory docs`로 정적 서버를 실행할 수 있습니다.

배포 시 `.github/scripts/build-pages.py`가 JS/CSS 내용의 해시를 파일명에 넣어
오래된 브라우저 캐시가 새 HTML과 섞이지 않도록 합니다. 화면 하단의 버전으로
수정본 적용 여부를 확인할 수 있습니다.

## 개발 검증

Chromium과 Node.js가 있는 환경에서 `.github/tests`의 고정된 개발 의존성을 설치한 뒤,
정적 서버를 실행하고 테스트합니다. 테스트는 별도 브라우저 프로필의 예시 저장소만 사용합니다.

```sh
npm --prefix .github/tests ci
python -m http.server 8000 --directory docs
# 다른 터미널에서:
PREVIEW_URL=http://127.0.0.1:8000 CHROMIUM_PATH=/usr/bin/chromium npm --prefix .github/tests test
```

배포 산출물도 `.github/scripts/build-pages.py /tmp/skycrm-site --commit <SHA>`로 만든 뒤
해당 경로를 정적 서버로 제공해 동일하게 검증할 수 있습니다.
